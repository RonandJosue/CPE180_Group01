# Overview
This project aims to utilize modern technologies like Artificial Intelligence and Cloud Computing. It aims to integrate the two technologies, creating an on-demand recommendation system.
To be precise, this project aims to help university students in meal prepping, with the model curating meals and recipes given the user's ingredients.
A fine-tuned Deep Seek model fed with recipes through rag will be hosted through Huawei's cloud services.
